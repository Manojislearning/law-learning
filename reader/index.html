How do I get a read-only GitHub token?
  1. Open GitHub's fine-grained token page.
  2. Choose the Manojislearning owner and select Only select repositories → LAW-NOTES.
  3. Set Contents: Read-only. Do not grant write permissions.
  4. Generate the token and paste it above. Keep it secret.

The token stays only in memory while this page is open, is sent only to GitHub’s API, and is never saved to this phone or committed to the website. Reopening the app requires reconnecting.
